# 15 秒文生视频导演工作流

## 一、接收素材后先做的事

1. 提取剧本事实：角色、唯一台词、动作先后、情绪转折、离场结果。
2. 提取连续性：角色参考图、身高、站/坐/跪、左右手、持物、伤势、前镜末态。
3. 画文字站位图：画面左/中/右、前/中/后、朝向、视线、障碍、路线。
4. 选择主媒介：真人实拍 / 3D 动画 / 2D 动画之一。
5. 选择一个主事件：15 秒不是一整场戏；必要时拆镜。

## 二、15 秒节拍建议

| 类型 | 推荐节拍 | 不要做什么 |
|---|---|---|
| 单人情绪 / 台词 | 建立 2s → 表演 9—11s → 反应/末态 2—4s | 频繁切镜、同时加大特效 |
| 双人对话 | 空间确认 2—3s → 正反打 9—10s → 关系末态 2—3s | 让二人每句话都换站位 |
| 群像对峙 | 全景 3—4s → 角色反应 7—8s → 危机末态 3—4s | 一条里直接完成对峙、开打、打完、离场 |
| 真人动作 | 定位与蓄力 3—4s → 一次主要交手 6—7s → 结果 3—4s | 多招连击、360°飘浮镜头、全屏特效 |
| 法术 / VFX | 动作源头 3s → 特效作用 6—7s → 余波/结果 4—5s | 让光效先于角色动作出现 |
| 广告 / 产品 | 产品识别 2—3s → 核心动作 8—9s → 品牌末帧 3—4s | 同条更换多套产品与多个场景 |

## 三、连续镜头卡

为每一镜建立五行，不要跳过：

```text
开场状态：谁在何处、面向谁、手里有什么、上一镜刚完成什么。
本镜主动作：只有谁从哪里向哪里做什么。
摄影机：景别、机位、一次明确运镜。
声音：唯一台词 / 允许音效 / 禁止声音。
末态：谁最终停在哪里、什么姿势、什么物体状态，供下一镜继承。
```

## 四、多人场景的硬规则

- 每名相似角色给稳定内部名：灵卫1/2、孩子a/b/c；内部名不能变成画面文字。
- 先全景证明人数和位置，再切近景。
- 需要保护关系时，明确“攻击者 → 保护者 → 被保护者”的前后顺序。
- 需要阻隔关系时，明确“网/门/桌/车/距离”位于谁与谁之间，以及谁绝不能跨越。
- 对话不等于换位：除非剧本有走位，角色只转头、转肩或移动半步。

## 五、输出方式

用户要“完整提示词”时，每个镜头给一个独立 `txt` 代码块，可直接复制。用户只要“检查”时，先给问题、原因、替换句，不重复长提示词。
