# 风格路由与模板索引

先选一种主媒介，再选题材。不要用“真人实拍 + 3D + 2D + 动漫 + 游戏CG”混合描述。

| 任务 | 读取模板 | 风格锚点 |
|---|---|---|
| 真人剧情、短剧、对话 | `01-真人剧情对话-15秒.txt` | 真实演员、摄影机、自然口型 |
| 真人动作、法术、武打 | `02-真人动作VFX-15秒.txt` | 真人动作先行、VFX后合成 |
| 仙侠 / 玄幻 / 古风 | `03-仙侠玄幻-15秒.txt` | 选真人仙侠或3D仙侠之一 |
| 高端 3D 动画、家庭向长片 | `04-3D家庭动画-15秒.txt` | 通用美式家庭向3D长片，不模仿具体工作室 |
| 2D 日系、国风、赛璐璐、漫画 | `05-2D动画-15秒.txt` | 2D线条与逐帧动作逻辑 |
| 都市短剧、爱情、职场、悬疑 | `06-都市短剧-15秒.txt` | 真人生活观察与精准表演 |
| 广告、电商、产品 | `07-广告产品-15秒.txt` | 产品主体、单一卖点、末帧 |
| UGC、抖音、Vlog、测评 | `08-UGC社媒-15秒.txt` | 手持机、自然交流、单一钩子 |
| 科幻、赛博、未来 | `09-科幻赛博-15秒.txt` | 先选真人科幻或3D科幻 |
| 恐怖、惊悚、悬疑 | `10-惊悚恐怖-15秒.txt` | 信息控制与观众视线 |
| 自然、纪录片、旅行、动物 | `11-自然纪录片-15秒.txt` | 观察式摄影、真实环境反应 |
| 转场、首尾帧、变身 | `12-转场首尾帧-15秒.txt` | 只用一个视觉桥接动作 |
| 成片检查与纠错 | `99-成片复盘输出.txt` | 先证据、后原因、再替换句 |

## 仙侠分流

- 用户要“真人电视剧 / 真人电影”：用真人实拍仙侠，禁止动漫、3D游戏感。
- 用户要“3D国漫 / 游戏CG”：用 3D 动画仙侠，不要再要求真实演员皮肤。
- 用户要“2D国风动画”：用 2D 动画仙侠，不要使用实拍摄影要求。

## 都市分流

- 都市短剧：人物关系、口型、空间、表演优先。
- 都市广告：产品、节奏、单一卖点、品牌末帧优先。
- 都市 UGC：真实手持、即时感、真实口语和一个钩子优先。
