# 调研来源与可迁移结论

本 Skill 于 2026-09-04 进行了定向资料调研。未声称穷尽全网；以下是用于提炼可迁移方法的代表性官方文档、开源资源和公开创作者平台资料。

## 官方 / 一手产品资料

- OpenAI Academy：Sora storyboard 教程
  https://academy.openai.com/public/videos/how-to-storyboard-with-sora-2025-03-11
  - 结论：用故事板组织多镜头叙事，先把剧情拆成可视化镜头。
- Runway Gen-4 Video Prompting Guide
  https://help.runwayml.com/hc/en-us/articles/39789879462419-Gen-4-Video-Prompting-Guide
  - 结论：提示词保持简单；图生视频文本聚焦运动；一条短片优先一个场景；逐项迭代主体动作、摄影机和环境反应。
- Google Cloud Veo 3.1 Prompting Guide
  https://cloud.google.com/blog/products/ai-machine-learning/ultimate-prompting-guide-for-veo-3-1/
  - 结论：使用“摄影 + 主体 + 动作 + 情境 + 风格”结构；角色和场景参考图可辅助多镜头一致性；首尾帧可控制过渡。
- Google 视频生成最佳实践
  https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/video/best-practice
  - 结论：输入图质量决定图生视频的身份、构图和风格；输入图已包含的信息不要在文本中重复；文本聚焦镜头、主体动画和环境变化。
- 阿里云百炼：文生视频 Prompt 指南
  https://docs.modelstudio.console.alibabacloud.com/zh/model-studio/text-to-video-prompt
  - 结论：可用“主体 + 场景 + 运动 + 声音”组织信息；摄影机和声音必须作为独立控制项。

## GitHub 开源与社区资源

- HuyLe82US / awesome-seedance-prompts
  https://github.com/HuyLe82US/awesome-seedance-prompts
  - 结论：将提示词按影视、动画、广告、UGC、动作、短剧等类型拆库；参考图与单镜头结构能提高一致性。
- opensource-works / awesome-seedance-prompts
  https://github.com/opensource-works/awesome-seedance-prompts
  - 结论：社区可验证片段与原始提示词适合做反向学习，但须针对自己的模型和素材重写，不能盲抄。
- khanof89 / awesome-video-prompts
  https://github.com/khanof89/awesome-video-prompts
  - 结论：基础结构可写为“场景 / 摄影机 / 视觉风格 / 补充效果 / 时长”，但连续剧情还必须补上站位、末态和声音。

## LiblibAI / 公开创作者工作流

- LiblibAI 关键帧控制工作流
  https://www.liblib.art/modelinfo/05de5d704c864fdea3889393b313b240
  - 结论：用提示词加关键帧控制动作；根据目标画风选择相应模型。
- LiblibAI 双人无限分镜工作流
  https://www.liblib.art/modelinfo/ec03d94ffe4f4a7dbfffa141b670e68a
  - 结论：同一参考图连续生成有助于双人身份与场景保持一致；不满意时应修改单个镜头提示而非重写整场。
- LiblibAI 人物一致性分镜工作流
  https://www.liblib.art/modelinfo/40aa0e11cc9842029ae87772680b1a61
  - 结论：主场景与三个分镜头分开管理，角色 / 风格资产独立锁定。

## 本项目经验如何融合

今天出现的“真人变 CG、人物串位、站姿错误、持物换手、角色增生、越界、文本咒文、台词乱说”被提升为强制验收项。社区模板可以提供创意类别，但不能取代：主站位圣经、全身姿态验证、单镜单事件、末态衔接和成片复盘。
