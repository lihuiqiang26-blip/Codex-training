# 连续性、真人感与成片复盘

## 生成前：强制连续性清单

```text
人数与身份：________
画面坐标：________
主朝向 / 视线：________
高度与姿态：________
左右手与持物：________
伤势 / 已发生动作：________
不可跨越边界：________
本镜移动路线：________
本镜末态：________
```

## 真人实拍硬约束

真人实拍不是只写“电影感”。需要同时出现：真实演员表演、真实皮肤/毛发、真实呼吸、重心、重力、脚步、衣物受力、摄影机景深、真实运动模糊、影视后期 VFX 合成。

真人镜头常用负面约束：

```text
禁止动漫、二次元、卡通、漫画、游戏CG、3D动画、虚幻引擎过场、塑料皮肤、蜡像脸、玩偶感、游戏动作捕捉感、无重力动作、镜头穿模、角色瞬移、人物变脸、额外肢体。
```

只有在用户明确要求 2D 或 3D 时，移除“禁止 2D/3D 动画”并替换为相应动画媒介规则。

## 常见失败 → 修正写法

| 失败 | 根因 | 精准修正 |
|---|---|---|
| 人物切镜后换边 | 没有画面坐标与末态 | “A始终画面左，B始终画面右；反打只换机位，不换角色位置。” |
| 人物距离过近 | 只写“对面” | “两人之间完整保留一片边界与明显空地，不得同处一个中近景平面。” |
| 站立人物变坐姿 | 只拍上半身 | “开场中全景看见双脚落地、双腿承重、背部接触目标；全程站立。” |
| 持物消失/换手 | 未锁左右手 | “右手持续持一件物体并自然下垂；左手完成其余动作；物体不得复制、变形或换手。” |
| 多出角色 | 群像未锁数量 | “全场仅六人；禁止第三名同类角色、背景路人和角色复制。” |
| 真人变CG | 只写“特效炸裂” | “先由真人演员完成动作，特效随后附着在动作源头；固定或手持实拍机位。” |
| 特效廉价 | 无物理因果 | “发力→能量源头→接触→光照/遮挡/受力→收束。” |
| 出现文字咒文 | 未覆盖载体 | “柱子、地面、背景、特效、道具均无任何可读文字、符号、字幕、UI或水印。” |
| 台词听不清 | 台词与动作挤在一起 | “先保证逐字普通话和口型；压缩动作、少切镜，不锁死逐秒语速。” |

## 成片复盘格式

先用以下顺序，不要直接给重写版：

```text
一、保留项：哪些身份、动作、镜头或声音是正确的。
二、错误：按严重度列出，标明时间段或画面。
三、成因：提示词哪一句缺失、含混或互相冲突。
四、替换指令：给可直接粘贴的短句。
五、下一版策略：拆镜、补全景、换参考帧或减少动作。
```

验收顺序：影像类型 → 人数/身份 → 站位/距离/朝向 → 站坐与双脚 → 左右手/持物 → 边界 → 文字与禁项 → 特效因果 → 台词与音效。
