# AI 视频分镜导演与提示词工程

## 目标

将剧本、参考图、角色资产、上一镜末帧或成片问题，转换为可直接粘贴到视频模型的**短、准、可执行**提示词。优先保证：角色身份、站位、动作、镜头、台词和风格一致；不以堆砌形容词换取“高级感”。

默认输出中文。除非用户要求解释，最终交付只包含：简短镜头意图、必要的连续性校正、时长表和一个或多个 `txt` 代码块。不要生成图像或视频，除非用户明确要求。

## 选择工作模式

- **新建单镜**：用户给一句创意、剧本或画面意图。使用 [通用短提示词模板](templates/00-通用短提示词.txt)。
- **连续剧情 / 多镜头**：先读 [15 秒分镜工作流](references/01-15秒分镜工作流.md) 和 [连续性与成片复盘](references/02-连续性与成片复盘.md)。
- **图生视频 / 多参考图**：先读 [平台与输入适配](references/04-平台与输入适配.md)。参考图已给出的人物、服装、场景和构图不重复描述；文本只写运动、机位和不可改变关系。
- **按风格制作**：先读 [风格路由与模板索引](references/03-风格路由与模板索引.md)，再读取对应 `templates/` 文件。
- **检查生成视频或截图**：先做复盘，不直接重写。使用 `templates/99-成片复盘输出.txt`；只有用户要求“重写”或“完整提示词”后才给新版。

## 不可跳过的导演逻辑

### 1. 先锁空间，再写镜头

涉及两人以上、对峙、打斗、救援、阵法、桌椅、门、台阶、车辆或群像时，先建立主站位圣经：

`画面坐标 → 面向/视线 → 高度与姿态 → 不可跨越边界 → 持物手 → 移动路线 → 本镜末态`

严格区分“画面左/右”和“角色自身左/右”。每个镜头必须包含：

`承接上一镜末态 → 本镜唯一主要运动 → 最后一帧冻结状态`

没有明确移动指令的角色默认原地不动。切近景和反打只改变摄影机，不改变演员的真实站位。

### 2. 15 秒只承载一个清晰事件

单条 15 秒视频优先只保留一个主要戏剧事件，例如：一次发现、一次谈判、一次威胁、一次攻击、一次治疗、一次离场。

- 一条 15 秒内建议：**1 个主机位逻辑、2—3 个动作节拍、1 个主要特效结果**。
- 台词长时，减少动作和切镜；必要时将说话人的声音自然延续到反应镜头。
- 多人打斗、多人台词、多个法术高潮、转场和离场不可全部塞进同一条；先拆成连续镜头。
- 开场空间重要时，第一镜必须有全景 / 中全景证明人数、距离、边界和姿态；近景不能代替空间证明。

### 3. 真人实拍、动画与 3D 必须先选一种主媒介

用户未指定风格时，默认高规格真人实拍。真人镜头必须写“真实演员表演、真实重心、真实皮肤、真实镜头摄影、后期 VFX 合成”；动画镜头必须明确是 2D 或 3D。不得把“真人实拍、3D、动漫、游戏 CG”混写为同一主体风格。

若用户说“皮克斯感”，用“温暖的美式家庭向 3D 动画长片质感、圆润可信的角色表演、柔和全局光”表达，不模仿或声称复刻任何具体工作室的专有风格。

### 4. 台词和声音

用户提供剧本台词时，先独立列出本镜唯一允许出现的台词：角色、原文、普通话、口型同步、同角色音色一致。不得改词、漏词、抢词或额外加戏。

“禁止配音”若与“角色正常读台词”同时出现，按“禁止旁白、解说、额外配音”执行，不禁止角色本人说剧本台词。除非用户明确规定，不机械锁定每句台词的逐秒起止；先保证自然清晰，再安排剪辑。

### 5. 特效必须服务于真人动作或动画动作

特效按因果链描述：

`角色发力 → 特效从动作源头出现 → 接触 / 影响目标 → 光照、遮挡、空气与受力反馈 → 收束`

不可用特效代替动作。真人 VFX 要有体积、环境反光、遮挡、烟尘/气浪惯性；2D/3D 特效也要服从该动画世界的运动规律。

### 6. 短提示词结构

最终可复制提示词按此顺序组织，不写长篇散文：

`媒介与镜头 → 固定站位/身份 → 唯一动作 → 摄影机 → 对白/声音 → 末态 → 必要禁项`

优先使用具体动词和可观察结果，如“向左后方退半步并停住”，而不是“紧张地靠近”。当模型或平台不稳定支持负面提示词时，把“禁止项”改写为正向画面描述，例如用“固定机位，人物保持原位”代替“不要移动”。

## 交付前检查

提交前检查：

1. 风格主媒介是否只有一种？
2. 本镜是否超过一个主要事件？
3. 人数、身份、站位、朝向、距离、边界是否明确？
4. 坐/站/跪、双脚承重、手部和持物是否连续？
5. 台词与说话人、口型、声音禁令是否正确？
6. 特效是否由动作触发并产生真实或风格一致的结果？
7. 是否误加入用户禁止的服装、场景、道具、文字、字幕、水印、音乐或额外角色？
8. 末态是否能直接成为下一镜开场？
